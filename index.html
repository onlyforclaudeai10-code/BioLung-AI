Minimal ESP32 REST API Contract

Your ESP32 WebServer / AsyncWebServer firmware should implement these 3 lightweight endpoints:

GET /api/status
Response JSON Structure:
{
  "temp": 24.8,
  "mq": 1120,
  "dark": false,
  "lightMode": 2, // 0=OFF, 1=ON, 2=AUTO
  "pumpMode": 2,  // 0=OFF, 1=ON, 2=AUTO
  "lightState": false,
  "pumpState": false,
  "powerOff": false,
  "threshold": 1500
}
GET /api/set?dev={device}&act={action}
Parameters: dev=light|pump|all , act=on|off|auto
Example: /api/set?dev=pump&act=auto
GET /api/threshold?val={number}
Updates MQ-135 trigger in ESP32 EEPROM/NVS
Fully CORS compliant REST API supported by ESPAsyncWebServer.
